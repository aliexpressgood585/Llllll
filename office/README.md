# משרד הסוכנים

דשבורד פיקסל-ארט של כל הפרויקטים וכל סוכני Claude Code: חדר לכל ריפו, שולחן לכל סשן, ומצב חי של כל סוכן
(עובד · מחכה לך · מוכן לבדיקה · הושלם · נתקע), כולל רשימת "צריכים אותך" וקישור לכל סשן.

- דף חי: https://claude.ai/artifact/1Q8ckjQycjaDSRXud3H3Ug
- `agent-office.html` — מקור הדף (Artifact עם יכולת `db`; הנתונים נקראים מאוספי `rooms`, `agents` ו-`meta`).
- `seed/` — צילום המצב שנטען למאגר (חדר לכל ריפו, מסמך לכל סשן).

עדכון: מבקשים מ-Claude "תעדכן את המשרד" — הוא מושך את מצב הסשנים העדכני וכותב אותו למאגר, והדף מתעדכן מיד.

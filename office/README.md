# משרד הסוכנים

בית פיקסל-ארט חי: כל פרויקט הוא דייר, והוא עובר בין החדרים לפי המצב של הסוכנים שלו —
חדר העבודה (עובד), הכניסה (מחכה לך), חדר הישיבות (מוכן לבדיקה), הסלון והמטבח (הושלם), חדר התיקונים (נתקע)
ועליית הגג (אין סוכן פעיל). הדיירים הולכים, עולים במדרגות ובסולם כשמצב משתנה; יום ולילה לפי שעון ישראל;
יומן פעילות, רשימת "צריכים אותך" וכרטיס פרויקט עם כל הסוכנים והקישורים.

- דף חי: https://claude.ai/artifact/1Q8ckjQycjaDSRXud3H3Ug
- `agent-office.html` — מקור הדף (Artifact עם יכולת `db`; הנתונים נקראים מאוספי `rooms`, `agents` ו-`meta`).
- `seed/` — צילום המצב שנטען למאגר (חדר לכל ריפו, מסמך לכל סשן).

עדכון: מבקשים מ-Claude "תעדכן את המשרד" — הוא מושך את מצב הסשנים העדכני וכותב אותו למאגר, והדף מתעדכן מיד.

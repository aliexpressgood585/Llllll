# משרד הסוכנים

מערכת ניהול לכל סוכני Claude Code על פני כל הפרויקטים, בעברית מלאה (RTL).

- **הבית החי** — כל סוכן הוא דמות גדולה וברורה שפועלת לבד: כותבת קוד, בודקת שרתים, מציגה בחדר הישיבות, מתקנת תקלות, דופקת בדלת כשהיא צריכה אותך.
  מצב "אוטונומי" (כולם בפעולה) או "לפי מצב"; זום, גרירה, מעקב מצלמה, מסך מלא, הדגשת פרויקט, בועות עם מה שהסוכן באמת צריך, יומן פעילות.
- **לוח בקרה** — מדדים, גרף פעילות, יעדים, מה מחכה לך, משימות היום, מה בקרוב.
- **לוח טיפול** — קנבן בגרירה לכל פריט שסוכן צריך ממך (חדש → בטיפולי → הועבר לסוכן → טופל), עם ביטול.
- **משימות ולוח שנה**, **פרויקטים** (עם הערות ותאריכי מעקב), **סוכנים**, **מסמכים**, **דוחות** עם ייצוא CSV, **יעדים והגדרות**.
- חיפוש גלובלי (Ctrl K), הוספה מהירה, התראות, קיצורי מקלדת (?), מצב כהה/בהיר.

- דף חי: https://claude.ai/artifact/1Q8ckjQycjaDSRXud3H3Ug
- קוד: `office/app/src` (React + TypeScript + Tailwind). בנייה: `npm run office:build` → `office/agent-office.html` (דף יחיד).
- נתונים: מאגר ה-Artifact — `rooms`, `agents`, `meta` (מצב הסוכנים), ו-`tasks`, `notes`, `triage`, `projectMeta`, `settings` (העבודה שלך).
- `seed/` — צילום המצב שנטען למאגר.

עדכון מצב הסוכנים: מבקשים מ-Claude "תעדכן את המשרד".

# חדר המסחר — פיוצ'רס

בוט מסחר ב-Binance USDⓈ-M Perpetuals, עם שישה סוכנים. לכל סוכן תפקיד אמיתי בקוד.

- **כשסוכן עובד:** בדף הוא נראה עובד רק כשהוא באמת מבצע פעולה, ומעל הראש מופיעה בועה עם הפעולה והמספרים שמאחוריה.
- **כשאין מה לעשות:** הסוכן יושב בעמדה וכתוב למה הוא מחכה.
- **תנועה בחדר:** דמות הולכת לעמדה אחרת רק כשהיא מעבירה עבודה אמיתית: נר חדש, סיגנל, אישור, או עסקה שנסגרה.

| סוכן | מה הוא עושה בפועל | מתי |
|---|---|---|
| איתן, סורק שוק | מושך מחירי mark, מימון ו-bid/ask, בודק אם נסגר נר ומעביר לאנליסטית | כל 10 שנ׳ (מחירים), כל דקה (נרות) |
| מאיה, אנליסטית | בודקת כל נר סגור ומוציאה סיגנל כשכל התנאים מתקיימים (פירוט מתחת לטבלה) | בכל נר 15m שנסגר, לכל חוזה |
| דוד, מנהל סיכונים | קובע גודל ומינוף, בודק מגבלות, ומאשר או דוחה (פירוט מתחת לטבלה) | בכל סיגנל |
| רוני, סוחר ביצוע | קונה או מוכר דרך ספר הפקודות האמיתי ומנהל את הפוזיציה עד היציאה (פירוט מתחת לטבלה) | בכל אישור, ובדיקה כל 10 שנ׳ |
| שירה, גזברית | שווי תיק, תשלומי מימון בשיעור האמיתי, הפסד יומי, ירידה מהשיא ועצירת חירום | כל 10 שנ׳, ובכל תשלום מימון |
| יונתן, כתב | סיכום שעתי, ודוח שבועי בכל יום שני (`futures-reports/`) | כל שעה, בכל יום שני |

**מתי מאיה מוציאה סיגנל:**
- מגמה לפי EMA20/50 על נרות של שעה.
- פריצה של 20 הנרות האחרונים.
- ATR בטווח סביר.
- מסנן RSI ומימון, כדי לא לרדוף אחרי מחיר.

**איך דוד קובע גודל ומינוף:**
- **גודל:** נגזר מהמרחק לסטופ, כך שכל עסקה מסכנת 1% מההון.
- **מינוף:** עד פי 5, במרג׳ין מבודד. אם מחיר החיסול קרוב לסטופ, המינוף יורד.
- **מגבלות:** מקסימום פוזיציות, הפסד יומי ועצירת חירום.

**איך רוני מנהל פוזיציה:**
- **יציאות:** סטופ, ויעד ב-2R.
- **נקודת איזון:** ב-1R הסטופ זז לנקודת האיזון, ומשם הוא נגרר 1R מאחורי המחיר.
- **זמן:** יציאה אחרי זמן החזקה מקסימלי.

## הרצה
```bash
npm run futures                 # http://localhost:8788
docker compose up -d --build futures
pm2 start ecosystem.config.cjs  # futures-desk
npm run futures:report          # הדוח השבועי מהמצב השמור
npm run futures:demo            # הדגמה על שוק סינתטי (לא נתונים אמיתיים) — http://localhost:8789
npm run test:futures            # בדיקת שבוע מדומה מקצה לקצה
```

## מה אמיתי ומה מדומה
- **אמיתי:** כל נתוני השוק מגיעים מ-Binance בזמן אמת: מחירי mark, שיעור המימון ומועד התשלום הבא, נרות, ספר פקודות וכללי החוזים (גודל צעד ומינימום).
- **מדומה:** הביצוע (מצב נייר):
  - פקודה עוברת דרך ספר הפקודות האמיתי, עם הגבלת החלקה של 0.2%.
  - עמלת taker של 0.05% בכל כיוון.
  - מימון בכל תשלום, לפי השיעור האמיתי.
  - חיסול לפי נוסחת המרג׳ין המבודד, עם שיעור התחזוקה של הדרגה הראשונה.
- **אין עדיין מצב כסף אמיתי לפיוצ'רס.** הוא יתווסף רק אחרי תקופת נייר ארוכה, ועם מפתחות שיש להם הרשאת Futures.
- **חסימה אזורית:** Binance חוסמת חלק מהאזורים (למשל כתובות IP מארה"ב), ולכן צריך להריץ ממחשב או מ-VPS באזור נתמך.
